# caption-pool — キャプションテンプレ母集団の準備

方針 (2026-09-23): 選択肢 (テンプレート) を大量に用意し、画面の一覧には出さずに持っておき、
状況に合う推奨パターンをそこから引き出せるようにする。このフォルダはその準備物を置く。

- `samples.json` — テンプレに流し込む見本データ。会場の種類ごとの典型データ (`typical`) と、
  収まり確認用の極端なデータ (`stress`)。項目名は `public/field-defs.js` と同じ。

## 美術館と普通のギャラリーは分けて扱う

Qriine の利用者はほぼギャラリー側 (個展・グループ展・公募展・アートフェア)。美術館のキャプションは
所蔵・寄贈のクレジット行、作家の生没年、和暦、価格なし、と書き方がまったく違い、文字数もけた違いに長い。
そのため:

- 見本データは会場の種類 (`venues`) ごとに分ける。
- 収まりの合格ライン (`thresholdBasis`) も会場ごとに別の統計から決める。
  ギャラリー系は Qriine 本番と Tate、美術館系だけに MoMA / 国立美術館の長さを使う。
  美術館の長さをギャラリー用テンプレの基準にしない (厳しすぎて良いテンプレまで落としてしまう)。

## データの出どころ

| 出どころ | 件数 (1950年以降) | 使い方 |
|---|---|---|
| Qriine 本番 Firestore | 入力済み 139件 / 11展覧会 | 統計のみ。他の作家の実データなので値はリポジトリに入れない |
| ジャパンサーチ 国立美術館所蔵作品 (`f-db=syozo`) | 2,153件 | 統計のみ。国内美術館風の見本は傾向に合わせた架空データ |
| MoMA collection (CC0) | 93,274件 | 統計 + 実在レコードを見本に使用 (`source: moma:<ObjectID>`、価格は架空) |
| Tate collection (CC0) | 16,304件 | 統計 (ギャラリー系の英語の長さの基準) |
| Art Institute of Chicago API (CC0) | 1,000件 | 統計 (作家名2行目に国籍・生没年を置く書式の確認) |

その他の傾向:
- Qriine: 価格は「数字のみ」が 52件中44件、寸法は「単位なしの数字2つ」が 57件中41件、タイトルが欧文のみの作品が 139件中28件。
- 国立美術館: 制作年の和暦併記・注記 96.6%、英題あり 95.5%、立体寸法 19.6%。
- MoMA: Untitled 系 16.6%、括弧・副題 32.4%、共作 6.6%、映像の尺 2.6%、素材 60字超 13.7%、
  版画などの複数部分の寸法 (composition / sheet) 39.7%。

キャプションの書き方の慣習 (ネット調査) の要点は Claude の memory `reference_caption_examples_research` に記録。
生データ (CSV 等) と集計スクリプトは容量と権利の都合でリポジトリに入れていない。
